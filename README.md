## 先分清：巴西原生家宽 IP 和圣保罗机房 IP 是两笔钱

原生家宽 IP 指的是这条地址在巴西本地运营商名下注册、属性接近家庭宽带。做账号运营的人买的就是这个属性，平台侧看到的是一条住宅属性地址，而不是机房段。WePC 巴西这条产品线给的是**巴西原生家宽 IP 加一个独立静态 IPv4**，官网把它定位在“发视频/起号”。

圣保罗机房 IP 的机房确实在巴西，本地延迟低、价格便宜，但 IP 属于数据中心段。跑网站、跑 API、跑数据库完全够用，用来养社交账号就不是同一回事了。

判断手上这条 IP 属于哪类，拿到机器后查一下 ASN 和 usage type，住宅段通常显示本地 ISP 名称，机房段显示的是数据中心服务商。这一步花不了两分钟，比看商家宣传语靠谱。

还有一个容易忽略的细节：WePC 巴西套餐在产品页上只标了“巴西”，没写具体城市。要明确圣保罗机房位置的，得看后面竞品那一节。

## 三个容易踩的配置限制

**流量是双向计费的。** 2TB 按 In+Out 合计，发视频、传素材都算在里面。超出后是限速，不是直接停机，这点比一刀切断要好。巴西档具体限到多少 Mbps，资料里没有写，别按“无限流量”理解。

**512MB 内存限制了不少用法。** 跑上传脚本、轻度浏览器自动化、定时任务是够的；本地剪视频、开一堆浏览器窗口做矩阵，这台机器扛不住。目前整理到的巴西档只有 1 核 512MB 这一种配置，要更高配置只能换机房或换商家。

**100Mbps 没写独享。** 高峰期实际能跑多少，只能自己测。
